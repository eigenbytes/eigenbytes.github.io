Step 1 — Frame the Question

Write a one-liner in your README/notebook:

  • Objective: Predict customer churn next month.
  • Unit of prediction: Customer-month.
  • Features available at prediction time: Activity in months 1..N (no future data).
  • Metric: F1 or ROC AUC, depending on costs.

Step 3 — Split Early to Avoid Leakage

Split before imputing/encoding, so test statistics don’t bleed into training.

from sklearn.model_selection import train_test_split
train_df, test_df = train_test_split(df, test_size=0.2, random_state=42, stratify=df["churn"])
train_df.shape, test_df.shape

3.1 Impute & encode using train-only stats

# Numeric imputation with train means
num = ["months_active","avg_sessions","avg_spend"]
train_imp = train_df.copy(); test_imp = test_df.copy()
train_imp[num] = train_imp[num].fillna(train_imp[num].mean())
test_imp[num]  = test_imp[num].fillna(train_imp[num].mean())
